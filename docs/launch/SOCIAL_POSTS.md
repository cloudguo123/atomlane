## Reddit

I made an MPL-2.0 open-source local Codex plugin for the part of parallel execution that usually worries me: preserving semantics. It is free for personal, research, and commercial use. One shared typed core keeps success/failure/data/lifecycle edges, artifacts, hashes, and capacity consistent; adapters tailor execution to the workload and real platform. macOS is Stable for the supported shell/package/Make/Compose/test frontends; native Windows has a scoped Preview for exact argv and declared PowerShell files, with Job Object containment and separate WSL/Docker realms. Unknown effects fail closed. Long runs stream real-time progress and savings.

The public controlled benchmark runs four independent tasks for 5+ minutes and reports 20m40s serial equivalent vs 5m10s wall (4.00× observed). The method and raw result are linked, and real-project neutral/negative results are welcome.

Source: https://github.com/cloudguo123/atomlane
